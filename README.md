# VetPharma Direct — Legal Telegram Distribution Model (Pitch Deck)

Интерактивная HTML-презентация (6 слайдов, формат `1280x720`) для проекта **VetPharma Direct** — легитимного канала дистрибуции дефицитных ветеринарных препаратов в экосистеме Telegram.

## Особенности
- **Single-File Architecture:** Весь код, стили и скрипты собраны в едином файле `index.html`.
- **Интерактивное редактирование (`contenteditable="true"`):** Любой текст, заголовок или показатель в `[скобках]` можно отредактировать прямо на слайде в браузере.
- **Речь спикера:** Встроенная выдвижная панель с тезисами выступления для каждого слайда.
- **Экспорт в PDF:** Поддержка чистой постраничной печати (`@media print`).

## Быстрый запуск
Откройте файл `index.html` в любом современном браузере или опубликуйте через **GitHub Pages**.
