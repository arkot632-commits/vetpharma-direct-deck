# VetPharma Direct — Legal Telegram Distribution Model

Интерактивная презентация (5 слайдов, формат `1280x720`) проекта **VetPharma Direct** — легитимного канала дистрибуции дефицитных ветеринарных препаратов в экосистеме Telegram.

## Структура (5 слайдов)
1. **Экосистема** — прямое бронирование и верификация партий без комиссий маркетплейсов.
2. **Легитимность** — 3 контура безопасности (справочное медиа, паспорт серии, агентская логистика).
3. **Воронка 5 мин** — путь клиента от обзора партии до трек-номера СДЭК.
4. **Трафик** — 4 канала привлечения целевой аудитории (B2C и B2B2C).
5. **Удержание и LTV** — триггер-календарь приема в боте и повтор заказа в 1 клик.
